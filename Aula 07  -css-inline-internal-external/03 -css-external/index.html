Este documento utiliza um arquio de CSS externo vinculado através da tag <link>

Vantagens do CSS Externo

  • Separação completa entre o conteudo (HTML) e designe (CSS)
  • Reutilização em multiplas páginas
  • Facilita a manutenção do código
  • Melhor organização do projeto
  • Pode ser armazenado no cache so navegador, melhorando a performace
